Everything in one place

Stop remoting in to click through consoles.

IIGO puts the IIS Manager, Services, Task Scheduler, Firewall and Windows Update behind one sign-in. It works from any browser, including your phone.

Web server

  • Websites

    Create sites, edit bindings and applications, and start or stop them. Covers most of what the IIS console does.

  • Application pools

    Add, delete, recycle and configure pools. See which applications use each one.

  • Free SSL certificates

    Request a certificate with simple-acme and install it on the site's HTTPS bindings in one step.

System

  • Live dashboard

    CPU, memory and network charts that refresh every 2 seconds, plus uptime and site counts.

  • Processes and services

    See what is running, who owns it and how much CPU it uses. Check every Windows service and its startup type.

  • Tasks, firewall and updates

    Manage scheduled tasks and firewall rules. Check for and install Windows updates.

Administration

  • Users and roles

    Give each person only the pages they need. Every feature is a permission you can switch on per role.

  • REST API

    Automate IIS and IP security rules with API keys. Keys are managed in the panel.

  • Plugins

    Add pages, permissions, background services and sign-in providers without forking the panel.

Monitoring

Know about problems before your users do.

IIGO watches the parts of IIS that fail quietly. When something goes wrong, it tells you where you already are.

  • App pool monitor. Restarts stopped application pools and tells you it did.
  • HTTPS monitor. Checks every running site for expiring certificates, missing certificates and host name mismatches.
  • Per-monitor channels. Choose which services each monitor sends through, and test each one from Settings.

Security

Built to sit on the Internet.

A control panel is a target. IIGO ships with safe defaults so you don't have to bolt them on later.

  • The default password must be changed at first sign-in.
  • Passwords need 12 or more characters.
  • Set allowed hosts to reject forged Host headers.

Two-factor sign-in

Require an authenticator app for administrators or for everyone.

HTTPS only

The sign-in cookie is never sent over plain HTTP.

Brute-force limits

Sign-in is rate limited, and accounts lock after repeated failures.

Encrypted secrets

Mail passwords, service keys and webhook URLs are encrypted with machine-bound keys.

Get started

Up and running in three steps.

The installer sets IIGO up as a Windows service that starts with the server and restarts itself if it stops.

  1. Run the installer

    Download IIGO Panel.msi from the latest release and run it as an administrator. Upgrades keep your data and settings.

    Latest release

  2. Add an HTTPS endpoint

    Point Kestrel at a certificate in appsettings.json, or put IIGO behind a reverse proxy.

    "Https": {
  "Url": "https://*:8443",
  "Certificate": {
    "Subject": "panel.example.com",
    "Store": "My",
    "Location": "LocalMachine"
  }
}

  3. Sign in and lock it down

    Sign in as admin with the default password from the README. You'll set a new one right away.

    Then add users, set up roles and turn on two-factor sign-in.

  • Windows Server 2012 or newer
  • IIS for web server features
  • Server 2012 may need the VC++ 2015-2022 runtime
